# Calculator

A small calculator interface built with React. The UI is organized into reusable components for the calculator display and buttons, with calculation logic implemented in the calculator component.

## Technology

- React
- JavaScript
- CSS
- Create React App

## Run locally

You need Node.js and npm installed.

```bash
git clone https://github.com/Reah3267/Calculator.git
cd Calculator
npm install
npm start
```

The development server will print the local URL to open in your browser.

## Build

```bash
npm run build
```

## Project structure

- `src/App.js` — application entry component
- `src/Components/Calculator/` — calculator interface and calculation logic
- `src/Components/NumberPad/` and button components — reusable UI elements

## Status

Beginner React project. Review the current implementation and test common calculations and edge cases before relying on it for anything beyond practice.
